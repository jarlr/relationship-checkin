# relationship-checkin

一个用「量化复盘」思路做的**关系健康度自我记录小工具**。
借用金融里看趋势、看波动的方法，记录自己在亲密关系里的行为与主观观察，
帮助复盘沟通节奏、情绪状态和付出平衡，提醒自己真诚相处、减少内耗。

## ⚠️ 定位与边界

- 本工具只做**自我反思**，不做对他人的揣测、预测或操控。
- 所有关于对方的字段（情绪基调、回应热度、压力状态）都是**你单方面的外在观察**，
  不等于对方的真实内心；记录越久越有参考价值，但不能替代当面沟通。
- 工具不提供推拉、试探、拿捏等套路建议；给出的提醒均指向「坦诚沟通、照顾双方状态」。

## 安装

```bash
pip install -r requirements.txt
```

## 用法

```bash
# 录入一条记录（交互式）
python main.py add

# 查看复盘摘要 + 生成趋势图 data/report.png
python main.py report

# 写入示例数据，便于先看效果
python main.py seed
```

## 记录字段

| 字段 | 含义 | 取值 |
| --- | --- | --- |
| `date` | 记录日期 | `YYYY-MM-DD`，默认今天 |
| `mood_self` | 自己当天情绪 | -2 很差 ~ 2 很好 |
| `mood_other` | 观察到的对方情绪基调（主观） | -2 很差 ~ 2 很好 |
| `other_engagement` | 观察到的对方回应热度 | 0 冷淡简短 ~ 3 热情主动 |
| `other_stress` | 观察到的对方压力状态 | 0 放松 ~ 2 压力明显 |
| `interaction` | 当天互动类型 | `chat` / `companion` / `conflict` / `apology` / `space` / `none` |
| `initiative` | 当天谁主动 | `self` / `other` / `mutual` / `none` |
| `effort_self` | 自己的投入程度 | 0 ~ 3 |
| `note` | 备注 | 自由文本 |

## 评分口径（透明可改）

健康度自评 0~100，起步 60：

- 双方情绪均值偏正加分，偏负扣分；
- 冲突占比越高扣分越多；
- 主动付出越失衡（全靠一方推进）扣分越多；
- 自己情绪波动越大、观察到对方压力越高，扣分越多。

评分只是复盘参考，不是关系的「估值」，更不能用来决定去留。
